# [70. Climbing Stairs](https://leetcode.com/problems/climbing-stairs)

Code available in: C++

Difficulty: Easy

Tags: Dynamic Programming, 1D Dynamic Programming

Pre-requisites: Basics of Dynamic Programming

## Approach
1. There's only one variable changing (the number of stairs), so it is 1D DP.
2. First step is to write the recursive function:
$f(i)$ where $i$ is the current stair number and $i \in (0, n)$.
3. Next, we have to write the base cases.
    1. Here, we have two of them: when $i == n$ that means we are already at the top of the stairs so the total number of ways to climb would be $1$.
    2. When $i > n$ that means we have crossed the threshold of the total number of stairs and this isn't a correct way to climb. So answer would be $0$.
4. Finally, we have to write the recurrence relation: $f(i + 1) + f(i + 2)$.
5. One thing to note here is that we can start the recursion from $i = 0$ or $i = n$. Depending on our choice, the base cases would change. In the above description, I have taken $i = 0$ to be the starting point but in the code below, I take $i = n$. The choice is yours but for consistency, I like to decrement my variables rather than increment them so that is why I start with $i = n$. Plus, this way, when we have to write the bottom-up approach, it becomes easier to translate the current code as it is practically already in bottom-up approach. Note that this trick might not always work but it is nice to stick to it when we can.
6. Optimisation via dp and then conversion into bottom-up approach is trivial here and can be easily understood by looking at the code.

## C++

### Top-down/Recursive Approach
Time Complexity: $O(2^n)$

Space Complexity: $O(n)$

```cpp
class Solution {
public:
    int climbStairs(int n) {
        if (n == 0) return 1;
        if (n < 0) return 0;
        return climbStairs(n - 1) + climbStairs(n - 2);
    }
};
```

### Top-down/Recursive Approach (with memoization)
Time Complexity: $O(n)$

Space Complexity: $O(n)$

```cpp
class Solution {
    int helper(int i, vector<int>& dp) {
        if (i == 0) return 1;
        if (i < 0) return 0;
        if (dp[i] != -1) return dp[i];
        return dp[i] = helper(i - 1, dp) + helper(i - 2, dp);
    }
public:
    int climbStairs(int n) {
        vector<int> dp(n + 1, -1);
        return helper(n, dp);
    }
};
```

### Bottom-up Approach
Time Complexity: $O(n)$

Space Complexity: $O(1)$ as we are not using the DP array

```cpp
class Solution {
public:
    int climbStairs(int n) {
        int prev = 1;
        int cur = 1;
        for (int i = 2; i <= n; i++) {
            int temp = cur;
            cur += prev;
            prev = temp;
        }
        return cur;
    }
};
```
